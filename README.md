# AI Resume Screener

An AI-powered resume screening application that compares a candidate's resume with a job description and provides a match score, missing skills, and improvement suggestions.

## Features

- Upload PDF/DOCX resumes
- Extract resume text automatically
- Analyze resume against job descriptions using Gemini AI
- Generate:
  - Resume match score
  - Missing keywords
  - Improvement suggestions
- Simple Streamlit user interface
- FastAPI backend

## Tech Stack

- Python
- FastAPI
- Streamlit
- Google Gemini API
- python-docx
- PDF text extraction
